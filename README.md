# AirCalibre

AirCalibre is an open-source initiative exploring environmental measurement through practical tools, shared knowledge, and community collaboration. GoodOne, a portable air-quality monitor, is one project within this broader effort.

The website introduces AirCalibre’s principles and projects, including the GoodOne project, its design, and its development journey.

## Technology

- Next.js with the App Router
- React and TypeScript
- Tailwind CSS
- Radix UI components
- Lucide icons

## Run locally

Requirements: Node.js and npm.

```sh
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
